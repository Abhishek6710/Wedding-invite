# Security Policy

## Reporting a vulnerability

This repository is a static wedding website published through GitHub Pages.

Please do not open a public issue for a suspected security vulnerability or exposed credential. Instead, contact the repository owner privately through GitHub so the issue can be reviewed before details are made public.

## Sensitive information

Do not commit passwords, API keys, access tokens, private keys, service credentials, or other secrets to this repository.

Because the repository is public, anything committed here should be treated as publicly accessible.

## GitHub Pages and Actions

The deployment workflow uses limited GitHub Actions permissions required for Pages deployment. Dependabot is configured to check the GitHub Actions dependencies weekly.
